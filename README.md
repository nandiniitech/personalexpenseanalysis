
# Personal Expense Analysis Using R

## About the Project
Personal Expense Analysis is a mini project developed using R to organize, analyze, and visualize personal expenses. It helps understand spending patterns across different categories such as Food, Travel, Shopping, Bills, and Entertainment.

## Objectives
- Create and organize a personal expense dataset.
- Calculate total and category-wise expenses.
- Identify spending patterns and major expense categories.
- Visualize expenses using graphs in R.
- Practice data analysis and visualization using R programming.

## Tools and Technologies
- **Programming Language:** R
- **IDE:** RStudio
- **Concepts:** Data Frames, Data Manipulation, Summary Statistics, Data Visualization

## Dataset
The project uses a sample expense dataset containing:
- `Expense_ID` – Unique ID for each expense
- `Category` – Type of expense
- `Amount` – Amount spent

Expense categories include Food, Travel, Shopping, Bills, and Entertainment.

## Project Workflow
1. Create a sample expense dataset using a data frame.
2. Display and inspect the dataset.
3. Calculate total expenses and category-wise spending.
4. Compare expenses across different categories.
5. Create graphs to visualize the results.
6. Interpret the spending patterns.

## Expected Results
- Total amount spent.
- Category-wise expense summary.
- Identification of the highest-spending category.
- Graphical representation of expenses.

## How to Run
1. Install R and RStudio.
2. Clone or download this repository.
3. Open the `.Rproj` file in RStudio.
4. Open the R script.
5. Run the code to generate the analysis and graphs.
